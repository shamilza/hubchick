# Hubchick CRM

**Hubchick** — это облегченная CRM-система и сервис онлайн-записи для самозанятых специалистов (beauty-мастера, репетиторы, консультанты).

## Основные возможности (MVP)
- **Для Мастера:** Управление графиком, услугами, базой клиентов и финансами.
- **Для Клиента:** Быстрая онлайн-запись через публичную страницу.
- **Автоматизация:** Напоминания о записях и расчет свободных слотов.

## Технологический стек
- **Backend:** FastAPI (Python 3.11+), PostgreSQL, Redis, SQLAlchemy.
- **Frontend:** React, Vite, TailwindCSS, Mantine UI.
- **DevOps:** Docker, Docker Compose.

## Структура проекта
- `backend/`: Исходный код серверной части.
- `frontend/`: Исходный код клиентской части.
- `docs/`: Документация и техническое задание.

## Установка и запуск (в разработке)
```bash
docker-compose up --build
```
